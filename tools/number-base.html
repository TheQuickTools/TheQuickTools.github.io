What is a Number Base?

A number base (or radix) is the number of unique digits used to represent numbers. The decimal system we use daily is base-10 (digits 0-9). Computers use binary (base-2), which only uses 0 and 1. Hexadecimal (base-16) is commonly used in programming and web design for color codes, memory addresses, and more.

Common Number Bases

Binary (Base-2)Used by computers. Only 0 and 1.
Octal (Base-8)Uses digits 0-7. Used in Unix permissions.
Decimal (Base-10)Standard everyday number system.
Hexadecimal (Base-16)Uses 0-9 and A-F. Common in programming.

Frequently Asked Questions

Why do programmers use hexadecimal?Hex is compact — one hex digit represents exactly 4 binary digits, making it easier to read binary data.
How do I convert binary to decimal?Multiply each bit by 2 raised to its position power, then sum all values. For example: 1011 = 1×8 + 0×4 + 1×2 + 1×1 = 11.
What is a byte?A byte is 8 bits (binary digits), ranging from 00000000 to 11111111 in binary, or 0 to 255 in decimal, or 00 to FF in hexadecimal.
